# 🚗 CarRental 

A full-stack car rental web application built with PHP and MySQL.

## Features
- 🔐 User Login & Registration
- 🚘 Browse available cars
- 🔍 Search & filter by category and price
- 📅 Select pickup and return dates
- 💰 Auto-calculated total price
- ✅ Booking confirmation
- 📋 Booking history

## Tech Stack
- PHP
- MySQL
- HTML & CSS
- WAMP Server

## Setup
1. Clone the repo into `C:/wamp64/www/carrental`
2. Import the database from `database.sql`
3. Update `db.php` with your credentials
4. Open `http://localhost/carrental`
